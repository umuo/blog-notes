# 退款报告生产化演练

输入是一份虚构的逗号分隔值（CSV）文件，退款金额为 8.00 元、2.00 元和缺失值 `NA`。验收结果是 2 条有效记录、平均退款 500 分。归档演练中同一个动作只允许产生一笔收据。

在仓库根目录使用 Python 3.10 或更新版本执行。只用标准库，SQLite 数据库驻留在内存中。无服务启动、网络访问或模型推理。

```bash
python3 experiments/production-refund/replay.py > /tmp/refund-production-results.json
diff -u experiments/production-refund/results.json /tmp/refund-production-results.json
```

| 文章 | 检查内容 |
| --- | --- |
| OPS-01 | 固定窗口限额、供应商模拟故障、重试边界、跨租户响应缓存 |
| OPS-02 | 审批策略决策、环境身份、目标、内容绑定、过期与不可用 |
| OPS-03 | 确定性四阶段时间样本、最近秩 P95、租约重复回收 |
| OPS-04 | 实际运行 SQLite 事务回滚与唯一键，队列重投用内存列表模拟 |
| OPS-05 | 20 个模拟结果的发布门槛、延迟、重复收据与流量回退 |
| OPS-07 | 旧结果转换、未知输出版本及同一副作用标识 |
| OPS-06 | 固定时间线的父子关系、阶段计时与首字测量 |

这些结果记录的是规则的重放。真实集群需要额外验证网络策略、资源清理、重复交付和版本迁移。虚拟耗时只用来检查计算，单位是毫秒。
